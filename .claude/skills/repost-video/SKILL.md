# 搬运视频 / 图文

只在**自己电脑上的会话**（手机 Remote Control 连着电脑）里做；云端会话下载不了视频 CDN，也不能登录账号。

## 0. 先确认版权
搬运前问一句：这是用户**自己的作品**，还是已**获得原作者授权**？都不是就不要发布，只能下载给用户自己看。平台对无授权搬运会限流甚至封号。

## 1. 下载
```bash
python3 -I .claude/skills/open-social-link/scripts/fetch_social.py "<链接或分享文字>" --download ~/Movies/repost
```
JSON 里的 `files` 是本地文件路径，`title` / `desc` / `tags` 可以作为新帖文案的素材。

## 2. 改写文案
按目标平台风格改写标题（小红书标题 ≤ 20 字）、正文和话题标签；授权内容在正文里注明原作者。发布前把标题、正文、文件给用户过目，用户确认后再发。

## 3. 发布
- **发到小红书**：用 `xiaohongshu-mcp` 的工具（先调 `check_login_status`；视频用 `publish_with_video`，图文用 `publish_content`，具体参数以工具列表为准），传本地绝对路径。
- **发到抖音**：用 `~/social-auto-upload`（见 docs/本地电脑安装.md），按它 README 里的抖音上传命令，传视频路径、标题和话题。
- 发布后把结果（成功/链接/报错）告诉用户。

## 注意
- 一天别连续发太多，间隔发布，避免触发风控。
- 不要批量抓取别人的账号内容。
