# 音乐剪辑（婚礼音乐工作流·云端版）

## 一首歌
```bash
python3 -I .claude/skills/music-clip/scripts/music_clip.py one "<文件路径或抖音/小红书链接>" --start 1:02 --end 2:30 --out <scratchpad>/music [--fade-out 3] [--name "入场-歌名"]
```

## 整场歌单
1. 把用户给的歌单（文字 / 截图 / Word）整理成 JSON，写到 scratchpad：
   ```json
   {"event": "张三李四婚礼",
    "entries": [
      {"position": "新人入场", "title": "歌名", "artist": "歌手", "source": "<文件路径或链接>", "start": "1:02", "end": "2:30"},
      {"position": "退场", "title": "歌名", "artist": "歌手", "source": "<同一文件>"}
    ]}
   ```
   - **保留原顺序和重复条目**（同一首歌在两个环节出现就写两条）；用户说取消的写 `"cancelled": true`。
   - `source`：用户上传的文件在 `/root/.claude/uploads/<会话>/` 下（看消息里给的路径）；也可以直接填抖音/小红书链接（自动下载并取音轨）。
   - 用户没给的字段不要编：没给 start 就从头，没给 end 就到尾。
2. 运行：
   ```bash
   python3 -I .claude/skills/music-clip/scripts/music_clip.py batch <歌单.json> --out <scratchpad>/music --zip
   ```
3. 用 SendUserFile 把 **zip**（多首时）或单个 mp3 发给用户；回复一句：成功几首、失败几首及原因。

## 规则（照做，不用问）
- 时间一律按**原曲**计；支持 `62`、`1:02`、`1:02.5`、`1分2秒`、`1：02`。
- 实际裁剪过的片段：默认开头 **0.5 秒淡入**（片段很短时最多一半长度）。整首不裁剪的不加淡入。
- 用户说"不要淡入" → `"fade_in": false`；说"淡入 2 秒" → `"fade_in": 2`。
- **淡出默认不加**，用户说了才加：`"fade_out": 3`。
- 文件名：`001 - 环节 - 歌名 - 歌手.mp3`（编号按出场顺序，跳过取消的）。
- 永不覆盖：用户改了时间点要重剪，把 `event` 改成新版本（如 `张三李四婚礼-v2`）再跑，旧版保留。
- 每个成品自动做时长核对 + 完整解码校验，记录在 `report.json`（含 sha256）。
- 默认输出原声 MP3。**去人声/伴奏**只有用户明确要求才做（云端暂未安装，需要时告诉用户一句"去人声还没装，要的话我装一下"）。

## 歌曲来源
- 最省事：用户在手机上直接**上传音频文件**（或带音乐的视频），或发抖音/小红书链接用视频的配乐。
- 网易云 / QQ 音乐账号下载：原工作流用用户自己扫码登录的账号，只能在 Windows 电脑上跑（见用户提供的「婚礼音乐工作流」安装包），云端没有接入。
