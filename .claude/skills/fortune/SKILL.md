# 算命（八字 + 紫微斗数）

用户在手机上用：**不要反问**，信息够就直接排，缺什么按下表默认，结果里注明假设。

## 1. 收集信息（缺了就用默认值，不要问）

| 信息 | 缺省处理 |
|---|---|
| 出生日期 | 必须有；没有就只回一句"发我出生年月日时和性别" |
| 农历/阳历 | 说"农历/阴历/x月初x"→ `--lunar`（闰月加 `--leap`）；否则当阳历 |
| 时间 | 不知道→ `--no-time`（只排三柱，不排紫微），注明"时辰不详" |
| 性别 | 从称呼推断（儿子/老公=男）；实在没有默认按男排并注明 |
| 出生地 | 给了城市就查经度加 `--lng`（真太阳时）；没给不校正 |

## 2. 排盘（必须跑脚本，不准心算干支）

```bash
python3 -I .claude/skills/fortune/scripts/chart.py --date 1990-05-17 --time 09:30 --gender 女 [--lunar] [--lng 116.4]
```

首次运行会自动安装 `lunar-python`（寿星万年历，节气精确）和 `iztro`（紫微斗数）到 `~/.cache/fortune-skill`。输出 JSON：八字四柱/十神/藏干/纳音/十二长生/空亡/五行个数/大运（标"当前"）/近三年流年；紫微十二宫主星亮度、生年四化、大限范围、今年大限与流年四化。

输出里的 `程序分析` 是查表/计算结果，**解读必须以它为准**：
- `旺衰`：五行力量打分（月令 ×3，藏干按本中余气 0.6/0.3/0.1），同党占比 → 身强/中和/身弱/极端格，并给出扶抑喜用、忌神。
- `调候用神(穷通宝典)`：日干 × 月令查《穷通宝典》通行用神表。
- `原局刑冲合害`、`今年(大运+流年)引动`：天干五合/相冲，地支六合/六冲/六害/三刑/自刑/三合半合/三会，逐对列出。
- `神煞`：天乙贵人、文昌、禄、羊刃、桃花、驿马、华盖。

自检：`--date 1893-12-26 --time 08:00 --gender 男` 必须得到「癸巳 甲子 丁酉 甲辰」，丁火身弱、调候甲庚。

## 3. 解读框架（按顺序，口语化，手机好读）

1. **命盘一览**：四柱、日主、生肖；紫微命宫主星、五行局。
2. **日主强弱与喜用**：直接用 `程序分析.旺衰` 的判断，并结合 `调候用神`：扶抑和调候一致→确定用神；不一致时，夏冬两季（巳午未、亥子丑月）调候优先，其余月份扶抑优先。标"极端格需复核"时，说明可能从格，两种看法都提一下。
3. **性格**：日主五行性情 + 突出的十神（如七杀多=魄力强压力大、伤官旺=聪明不服管、印多=依赖思考）+ 紫微命宫主星特质。
4. **事业财运**：官杀/财星状态，紫微官禄宫、财帛宫。
5. **感情婚姻**：男看财星、女看官星，日支为配偶宫；紫微夫妻宫主星和化忌。
6. **当前大运 + 今年流年**：用 `今年(大运+流年)引动` 列出的冲合刑害（冲日支=感情/住所变动，冲月支=工作环境变动，合喜用=助力），看流年干支五行是喜还是忌，再结合紫微流年四化落在哪个宫。给出 2–3 条具体建议（方向、颜色、行业五行）。
7. 结尾一句："命理仅供参考娱乐，路还是自己走的。"

常用对照：
- 五行生：木→火→土→金→水→木；克：木克土、土克水、水克火、火克金、金克木。
- 六冲：子午、丑未、寅申、卯酉、辰戌、巳亥；六合：子丑、寅亥、卯戌、辰酉、巳申、午未。
- 三合局：申子辰水、亥卯未木、寅午戌火、巳酉丑金。
- 五行对应：木=绿/东/教育文化，火=红/南/互联网餐饮，土=黄/中/地产，金=白/西/金融，水=黑蓝/北/物流贸易。

## 4. 其他玩法

- **合婚**：两人各排一次，看日柱天干五合/地支六合六冲、五行互补、生肖冲合，紫微看双方夫妻宫。
- **宝宝起名**：排盘后按喜用神五行选字，给 5–8 个名字，标每个字的五行。
- **只问今年运势**：仍需排盘，回复只写第 6 步。

## 规则

- 回复控制在手机一屏半以内，先结论后理由，少堆术语，术语后加白话解释。
- 不做恐吓式断语（不说"克夫""短命""血光之灾"），健康、生死、重大投资只说倾向，提醒以现实为准。
- 用户要完整盘面数据时再贴 JSON 重点字段，否则只给解读。
