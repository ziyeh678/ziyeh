# ziyeh

在手机上让 Claude 打开小红书 / 抖音链接、下载和搬运视频。

| 用法 | 打开小红书 | 打开抖音 | 下载 / 搬运 |
|---|---|---|---|
| **手机 → 遥控自己电脑（推荐）** | ✅ | ✅ | ✅ |
| 手机 → 纯云端会话（环境选 `ziyeh`） | ✅ 读内容 | ⚠️ 只能读分享文字 | ❌ |

- 推荐方案的一次性安装：[docs/本地电脑安装.md](docs/本地电脑安装.md)
- 技能：`.claude/skills/open-social-link`（打开链接）、`.claude/skills/repost-video`（搬运）
