# 手机遥控电脑：小红书 / 抖音 打开链接 + 搬运视频

**为什么要用自己的电脑**：云端服务器在海外，抖音不给它返回视频，小红书登录也容易被风控。
你的电脑在国内、是家用网络、能扫码保持登录，所以功能最全。手机通过 **Remote Control** 遥控电脑上的 Claude Code，在手机上发链接就行（前提：电脑开着、没休眠）。

## 一次性安装（约 15 分钟）

### 1. 装 Claude Code 并拉取本仓库
- 安装 Claude 桌面版（https://claude.ai/download），或命令行版 Claude Code。
- 克隆仓库：`git clone https://github.com/ziyeh678/ziyeh.git`
- 装 Python 3（Mac 自带；Windows 去 python.org 下载，勾选 "Add to PATH"）。

### 2. 小红书：xiaohongshu-mcp（读笔记 + 发图文/视频）
- 到 https://github.com/xpzouying/xiaohongshu-mcp 的 Releases 下载对应系统的程序（或用 README 里的 Docker 方式）。
- 先运行登录工具，用小红书 App 扫码登录（登录状态会保存在本地）。
- 再运行主程序，让它一直开着（默认监听 `http://localhost:18060/mcp`）。
- 本仓库的 `.mcp.json` 已经配好这个地址，Claude Code 在仓库目录里启动时会自动连上。

### 3. 抖音：social-auto-upload（发抖音视频）
- `git clone https://github.com/dreammis/social-auto-upload ~/social-auto-upload`
- 按它的 README 安装依赖并完成抖音扫码登录（生成 cookie）。
- 下载抖音视频用本仓库自带的脚本，不需要额外装。

### 4. 打开 Remote Control，让手机能连
- 桌面版：设置 → Claude Code → Remote Control，把本仓库文件夹加进去并打开。
- 命令行版：在仓库目录里运行 `claude remote-control`。
- 手机打开 Claude App → Code，就能看到这台电脑，进去直接发链接。

## 日常用法（手机上说）
- "看看这个：<小红书/抖音链接>" → 读取标题、正文、数据。
- "把这个视频下载下来" → 存到电脑 `~/Movies/repost`。
- "把这个视频搬到小红书，文案改一下" → 下载 → 改写文案给你确认 → 发布。

> ⚠️ 只搬运**自己的作品**或**已获授权**的内容，无授权搬运会被平台限流或封号。
